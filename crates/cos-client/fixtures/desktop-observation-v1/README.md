## Hashes (committed LF bytes)

Each hash is the SHA-256 of the file's **committed bytes (LF)** - the bytes
Git stores in the blob, not the CRLF working-tree spelling produced by
`core.autocrlf=true` on Windows. The capture script writes LF explicitly
and hashes the bytes it wrote, so the table does not depend on the
checkout's newline translation. Verify from the repository root with

    git cat-file blob HEAD:orchestrator/fixtures/desktop-observation-v1/<name>.json | sha256sum
