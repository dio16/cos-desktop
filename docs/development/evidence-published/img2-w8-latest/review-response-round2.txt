5. 残存指摘
A-W8-R2-01 — Malformed WICでworker/probe outcome矛盾を受理する

分類：ACTIONABLE NON-BLOCKING

対象：apps/desktop/devtools/img2/w8_jpeg_verify.py:423–449

修正によりmalformedの2 legsは必須になりました。しかし、malformed WIC legではprobe_result.outcomeに基づく分類とexit/outputを確認する一方、worker.outcomeおよびterminal traceとの一致は検査していません。

独立再現：

元Nativeのmalformed_truncatedに対して、WIC workerの1フィールドだけを変更しました。

Python
実行
worker["outcome"] = "error"

変更前の実記録では、worker.outcomeもprobe_result.outcomeもdecodedです。

改変後は両者が矛盾しますが、現行検証器は次を返しました。

プレーンテキスト
ok = true
tamper_not_verified = 2
closure_eligible = false

closure_eligible=falseはGit SOURCE未検証によるものであり、今回のworker矛盾を拒否した結果ではありません。

最小修正条件： Malformed WIC legについて、worker.outcome、probe_result.outcome、terminal trace outcomeの一致を必須化してください。Decodedとfailureの両経路で、exit code・output publication・trace terminalを観測outcomeと対応付けます。

TAMPER_NOT_VERIFIEDというcontent分類は維持してください。WIC/GDI+ probeの変更は不要です。

A-W8-R2-02 — 正常GDI+のsource geometry申告を偽装できる

分類：ACTIONABLE NON-BLOCKING

対象：apps/desktop/devtools/img2/w8_jpeg_verify.py:271–289

正常GDI+ legではdecoder identity・outcome・exit code・output hashを確認していますが、probe_result.width/heightを独立解析されたJPEG SOF geometryと照合していません。

独立再現：

正常dc_gray_8x8のGDI+ legで次の1項目を変更しました。

Python
実行
leg["probe_result"]["width"] = 2048

元JPEGは8×8で、保存PNGも8×8です。

しかし、現行verify()はok=trueを返しました。

最小修正条件： GDI+のprobe_result.width/heightを独立marker parserから取得した寸法と照合し、input_bytes・output_bytesも元fixtureと実出力バイト数に結合してください。

GDI+に存在しないheader-only stageやprocess traceを追加する必要はありません。
